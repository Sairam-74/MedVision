# Measured TRAIN BatchNorm context sensitivity

The16 prespecified TRAIN examples from the learned-gradient diagnostic were processed with E5's same selected checkpoint. Stored-statistics evaluation produced exactly the same probability maps for batch1 and batch2 in this CPU diagnostic: maximum difference0, changed thresholded pixels0, changed case decisions0. The intended inference mode was consistent across these batch sizes.

Using current-input BatchNorm statistics instead of stored statistics substantially changed maps: maximum absolute probability differences0.9485 at batch1 and0.9317 at batch2. Relative to stored-statistics evaluation, thresholded pixels changed1841 and1164, with4 and2 case decisions changing, respectively. Eight-positive mean grid Dice was0.126681 in stored-statistics evaluation,0.150811 with batch1 current-input statistics and0.142600 with mixed batch2 statistics. These are small diagnostic-sample values, not full TRAIN/validation results or candidate improvements.

The gap confirms sensitivity to normalization context, but does not show that inaccurate stored statistics are the primary cause of the model's poor fit. The sample deliberately mixes positives/normals equally and differs from natural TRAIN prevalence and augmentation. The modest sample Dice changes do not close the observed segmentation gap. Current-input statistics were never estimated from VAL, CAL or reserved TEST. No optimizer steps or saved candidate checkpoint occurred; in-memory BatchNorm buffer changes were discarded and the disk checkpoint remained identical.
